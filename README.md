# e-plantShopping

## Paradise Nursery Shopping Application

Paradise Nursery is an online plant shopping application where users can explore and purchase beautiful houseplants.

### Project Overview

The e-plantShopping project allows users to browse houseplants, view their prices, and add plants to a shopping cart.

### Features

- Home page introducing Paradise Nursery.
- Plants page displaying houseplants in different categories.
- Product images, names, descriptions, and prices.
- Add to Cart functionality.
- Shopping cart with quantity controls.
- Increase and decrease plant quantities.
- Remove plants from the cart.
- Automatic calculation of the total cost.
- Checkout and Continue Shopping buttons.

### Technologies Used

- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
