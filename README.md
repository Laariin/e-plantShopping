# Rayo Agro

## Rayo Agro Shopping Application

Rayo Agro is an online plant shopping application where users can explore and purchase a variety of beautiful plants for their homes, gardens, and agricultural needs.

## Project Overview

The Rayo Agro project allows users to browse plants, explore different categories, view product details and prices, and add their favorite plants to a shopping cart.

## Features

- Home page introducing Rayo Agro.
- Plants page displaying plants in different categories.
- Product images, names, descriptions, and prices.
- Add to Cart functionality.
- Shopping cart with quantity controls.
- Increase and decrease plant quantities.
- Remove plants from the cart.
- Automatic calculation of the total cost.
- Checkout and Continue Shopping buttons.
- Responsive and user-friendly interface.

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Laariin/e-plantShopping.git
   ```

2. Navigate to the project directory:

   ```bash
   cd e-plantShopping
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Build the project:

   ```bash
   npm run build
   ```
